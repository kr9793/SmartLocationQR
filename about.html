iSmartComp Connect

A campus location directory for MMMUT, Gorakhpur. Scan a QR code posted anywhere on campus and get an instant, mobile-friendly page with photos, coordinates, and turn-by-turn directions to that spot.

🔎

Instant lookup

Every location has its own QR code linking straight to its page — no app install required.

🗺️

Map & directions

Each page embeds a live map preview and a one-tap "Get Directions" link to Google Maps.

📱

Works on any phone

Built as a lightweight static site — fast to load over campus wifi, no login needed.

🔗

Share anywhere

Copy coordinates or share a location link directly from the location page.

UNDER THE HOOD

How it's built

iSmartComp Connect is a static site — plain HTML, CSS and JavaScript, with all location data stored in a single locations.json file. QR codes are generated in bulk with a small Python script and point to each location's page by ID. The site is hosted on GitHub Pages.
